🤖 Unit 5: IT Workshop & Generative AI Tools

Simple Guide on Software Tools, Environment Setups, and AI Coding Support

📖 1. What is IT Workshop? (Simple 3-Line Definition)

Line 1: IT Workshop is a practical subject that teaches students how to use software tools like Visual Studio Code, terminal commands, and folder setups.
Line 2: It guides students on how operating systems work and how to configure development environments for building real software.
Line 3: It also teaches how to use modern Generative AI tools (like ChatGPT) responsibly to fix code bugs and write project documentation.

💻 2. How IT Workshop Works in Our Project

IT Workshop principles were used directly to create and run this Assignment Deadline Tracker:

  • 1. Project File Management: Used VS Code to structure files cleanly into templates/ (HTML pages) and static/ (CSS styles and JS scripts).
  • 2. Terminal Execution: Used command-line terminal operations (python app.py) to launch the local Flask web server at http://127.0.0.1:5000.
  • 3. AI Debugging & Styling: Leveraged AI coding tools to debug SQLite database connection errors and write responsive CSS designs for the user dashboard.

❓ Self-Assessment Practice Questions

Question 1: What is the main purpose of IT Workshop?

Answer: To teach practical skills in using development tools, managing terminal commands, and setting up coding environments.

Question 2: How does IT Workshop help in running our web app project?

Answer: It provides the folder structure, VS Code editor setup, and terminal commands needed to run the local Flask server smoothly.
