📐 Unit 3: Applied Mathematics — Matrices

Super Simple Guide on Grids, 2x2 Matrices, and How They Power Our Website Table

📖 1. What is a Matrix in Simple Words?

Simple Definition: A Matrix is just a clean grid box with horizontal Rows (left-to-right) and vertical Columns (top-to-bottom).

Real-World Example: Think of a weekly class timetable or a simple shopping bill table. The lines going across are Rows, and the lines going down are Columns.

🧩 2. Understanding a 2x2 Matrix (Easy Example)

A 2x2 Matrix is a grid with 2 Rows and 2 Columns. That means it holds a total of 4 numbers or items.

2x2 Marks Grid Example

[ 85      90 ] ➔ Row 1 (Student A: Maths, Python)
[ 78      92 ] ➔ Row 2 (Student B: Maths, Python)

1. Top-Left Box (85): Marks of Student A in Maths.

2. Top-Right Box (90): Marks of Student A in Python.

3. Bottom-Left Box (78): Marks of Student B in Maths.

4. Bottom-Right Box (92): Marks of Student B in Python.

📊 3. How Matrices Work in Our Assignment Tracker

Our website database stores your assignments as a matrix grid. Look at this small sample assignment table:

S.No (Col 1) Assignment Name (Col 2) Deadline Date (Col 3) Priority (Col 4)
Row 1 Python Lab Record 2026-07-28 🔴 High
Row 2 Maths Unit Quiz 2026-07-30 🟢 Low

💡 Why this Matrix Grid helps our Website:

1. Every Row is One Task: Row 1 holds everything about "Python Lab Record". Row 2 holds everything about "Maths Unit Quiz". Data never mixes up.
2. Every Column is One Feature: Column 2 lists all assignment names, and Column 3 lists all deadline dates.
3. Super Fast Searching: If you click "Edit", the website goes straight to Row 1, Column 2 to change "Python Lab Record" instantly!
