💻 Unit 2: Data Structures & Sorting Techniques

Beginner-Friendly Guide on Data Storage and Sorting Algorithms

📖 1. What is a Data Structure? (Simple Definition)

Simple Definition: A Data Structure is a smart container used to organize, store, and manage data inside a computer's memory so that we can find, update, or use it easily.

Real-World Example: Think of your school bag compartments. If you put books, pens, and lunch in separate pockets instead of one big pile, you can find your pen in seconds. Data structures work like those organized pockets in computer memory.

🛠️ 2. How Data Structures Help Our Project (In Simple Lines)

• Organized Memory: Data structures store all user assignments inside a clean table (List of Records) so no information gets mixed up or lost.
• Quick Access: They allow the website to quickly fetch, edit, or delete any specific assignment instantly using unique ID numbers.
• Automatic Sorting: They help sort assignments by deadline date so urgent tasks always stay at the top of the student's dashboard.

🔄 3. The Three Core Sorting Techniques

1️⃣ Bubble Sort

How it works: Compares neighbor items in pairs and swaps them if they are in the wrong order until the largest value bubbles up to the end.

One Line Example: Unsorted [5, 3, 1] ➔ Swap (5,3) ➔ [3, 5, 1] ➔ Swap (5,1) ➔ [3, 1, 5] ➔ Swap (3,1) ➔ [1, 3, 5] (Sorted)

2️⃣ Selection Sort

How it works: Scans the entire list to find the smallest item and swaps it into the first position.

One Line Example: Unsorted [4, 1, 3] ➔ Find min (1), swap with 4 ➔ [1, 4, 3] ➔ Find min in [4,3] (3), swap with 4 ➔ [1, 3, 4] (Sorted)

3️⃣ Insertion Sort

How it works: Picks one item at a time and inserts it into its correct position among already sorted items (like playing cards).

One Line Example: Unsorted [4, 2, 3] ➔ Insert 2 before 4 ➔ [2, 4, 3] ➔ Insert 3 between 2 and 4 ➔ [2, 3, 4] (Sorted)
