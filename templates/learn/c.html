⚙️ Unit 4: C Programming & Algorithmic Logic

Beginner-Friendly Textbook Guide on Basic Logic and Step-by-Step Execution

📖 1. What is C Language? (Simple Definition)

Simple Definition: C Language is one of the oldest, most foundational computer programming languages. It acts as the mother of modern programming languages because almost all modern languages (like Python, C++, and Java) borrowed their basic syntax and logic structures from C.

Real-World Analogy: Think of C language like learning how a car engine works from the inside. While driving an automatic car is easy, knowing how the engine components connect helps you understand how the whole vehicle functions. C teaches you how computer memory and instructions work at the deepest level.

🧩 2. What is an Algorithm? (Easy Explanation)

Simple Definition: An Algorithm is simply a step-by-step set of instructions written in plain order to solve a specific problem.

Real-World Example (Making Tea):
• Step 1: Take a pot and add water.
• Step 2: Turn on the stove and boil the water.
• Step 3: Add tea powder and sugar.
• Step 4: Pour milk and boil for 2 minutes.
• Step 5: Filter the tea into a cup and serve.

If you skip Step 2 or do Step 5 before Step 1, the result fails! In programming, computers follow instructions step-by-step in the exact same logical order.

💻 3. How C Programming Logic is Used in Our Assignment Tracker

In our Assignment Deadline Tracker project, C programming logic forms the step-by-step algorithm executed whenever a student adds a new assignment:

Step-by-Step System Algorithm:
-----------------------------------
Step 1: Open the "Add Assignment" form.
Step 2: Read user inputs (Subject, Title, Deadline, Priority, Status).
Step 3: Check IF inputs are empty.
        IF empty ➔ Show warning alert.
        IF valid ➔ Proceed to Step 4.
Step 4: Connect to SQLite database file.
Step 5: Save record into assignments table.
Step 6: Refresh Dashboard and show updated list.

Why this helps: Without strict step-by-step algorithmic logic, the computer would attempt to save data into the database before the user even types the assignment details, causing system crashes!
