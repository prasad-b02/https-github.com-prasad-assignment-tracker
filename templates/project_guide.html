Single-Line Purpose of Each File:

  • app.py: Connects user actions on the browser to the database.
  • database.py: Creates the database storage tables automatically on startup.
  • assignments.db: Stores all saved student profiles and assignment records.
  • requirements.txt: Tells Python to install the Flask web library.
  • style.css: Gives the entire website its dark mode theme and table styling.
  • script.js: Shows a confirmation alert box before deleting an assignment.
  • index.html: Displays all saved assignments in a neat table view.
  • profile.html: Lets students type and save their name, branch, and college.
  • project_guide.html: Explains how this entire project is built and managed.
  • add_assignment.html: Provides the form to type and add a new task.
  • edit_assignment.html: Pre-fills existing task details so you can update them.
  • learn/index.html: Shows the main menu for all 5 subject lessons.
  • learn/python.html: Teaches Python basics and Flask web routing.
  • learn/dsa.html: Teaches Data Structures and 3 core sorting techniques.
  • learn/math.html: Teaches Matrices and 2D database table mapping.
  • learn/c.html: Teaches C Language and step-by-step algorithmic logic.
  • learn/it.html: Teaches VS Code usage, terminal execution, and AI tools.

👤 2. How Profile Setup Works (Simple Steps)

• Step 1: Enter your Name, Branch, and College into the profile form.
• Step 2: Click Save Profile Details to send your details to Python.
• Step 3: Python saves your details inside assignments.db.
• Step 4: All pages immediately update to show your name and college in the header.

✏️ 3. How to Edit Assignments (Simple Steps)

• Step 1: Click ✏️ Edit next to any task on the dashboard.
• Step 2: Python fetches that task's details from the database.
• Step 3: The edit page opens with your existing data already typed in.
• Step 4: Change whatever field you want (like Status or Priority) and click Update.
• Step 5: Python runs the SQL UPDATE command to save your changes and refreshes the table.

🎨 4. Priority Levels & Color Rules

🔴 Red (High Priority)

Hard / Urgent Tasks: Due in 1–2 days. Requires immediate focus.

🟡 Yellow (Medium Priority)

Medium Tasks: Regular lab reports due in 3–6 days.

🟢 Green (Low Priority)

Easy / Long-term Tasks: Reading assignments due after a week or more.
